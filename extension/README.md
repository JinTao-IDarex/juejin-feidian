# 沸点抽卡 · Juejin Pin Gacha（浏览器扩展）

实时抓掘金最新沸点，摆成一桌牌：一张是沸点原文，一张是 AI 犀利解析。
**弹窗式界面，只弹这两张牌**——牌以外没有页面装饰，靠四角浮标完成所有操作。
扑克牌比例（2.5 : 3.5），点数由热度决定。

## 装

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中本目录（`extension/`）
4. 点工具栏图标 → 弹窗里点 **「弹卡牌 →」** 打开牌面层

**注意**：`弹卡牌 →` 目前是在新标签页里以居中浮层的方式打开（浏览器不允许扩展直接往任意网页
右上角塞无边框浮层）。要真正贴在当前网页上，见下面「做成网页内浮层」。

## 界面

- **只有牌**：并排两张竖牌，比例按真实扑克 2.5 : 3.5。
  左牌是**原文**（◆ 红），右牌是**犀利解析**（♠ 黑）。牌后面一圈柔光把浮层和网页分开。
- **四角浮标**（都是半透明玻璃质感，浮在牌外，不占页面）：
  - 左上：`沸`｜`⟳ 抓最新`｜`洗牌`｜`♥ 收藏数`｜`⚙`｜`✕ 关`
  - 左上第二行：搜索框（搜沸点 / 作者 / 话题 / 点评）
  - 右上：`第 n / N 张 · 点数`、`喜欢 n · 已评 n`，下面一条进度细线
  - 底部：`← 上一张`｜`评论`｜`复制`｜`♥ 喜欢`｜`抽下一张 →`
- **点数**：按热度（赞 + 评论×2）把牌堆排序后分 13 档，映射 A、2…10、J、Q、K——
  抽到 K 就是这批里最热的。收藏夹里也显示点数，等于在攒一副牌。
- 四角是镜像索引（右下旋转 180°），牌面三段式：牌头（作者/模型）、牌身（正文/点评）、牌脚（数据/操作）。
- 翻牌有左右发牌动画。

## 做成网页内浮层（可选）

想让卡牌直接贴在你正在看的网页右下角，而不是另开一个标签页：

1. 用 Chrome 自带的 **窗口命名** 手法，把整个浏览器窗口变成浮层应用窗口：
   在网页上按 `F12` 打开控制台，执行
   ```js
   open(location.href, '_blank', 'width=1180,height=700,popup=1')
   ```
   会弹出一个无地址栏的小窗，在里面打开 `chrome-extension://<扩展ID>/app.html`。
2. 或者用支持侧边浮层的扩展/脚本（如 Tampermonkey）注入一个 `<iframe
   src="chrome-extension://<扩展ID>/app.html">`——`app.html` 已经登记在
   `web_accessible_resources` 里，允许被任意网页 iframe 引用。
   牌层内的 `✕` 会向父窗口 `postMessage({type:'pin-gacha-close'})`，父页面监听即可关闭。


## 配 AI 点评（必需，否则只有沸点没有点评）

图标 → `⚙` 设置页 → 「AI 接口」：

| 服务 | Base URL | 模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本机 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b`（Key 随便填） |

填好点 **测试接口**，通了再保存。Key 只存在本机 `chrome.storage.local`，不上传。

## 用

- 底部按钮：上一张 / 评论 / 复制 / 喜欢 / 抽下一张
- 键盘：`←` `→` 翻牌，`空格` 下一张，`L` 喜欢，`C` 评论，`R` 重抓，`Esc` 先关抽屉、再关牌层
- **AI 点评**：同一张牌可给 2~3 种性格版本（设置页里勾选），牌上点标签切换；
  解析牌底部有「重写」「复制」「用这句评论」「补 5 条」
- **喜欢**：本地收藏；如果浏览器里已登录掘金，会同时真实点个赞（走掘金自己的接口）
- **评论**：弹出框里能「贴入 AI 点评」→ 直接发（用你已登录的身份），或复制后去原文粘贴
- 抓到新沸点会在图标上显示未读角标；设置页可开定时自动抓（默认 15 分钟）与系统通知

## 说明与边界

- 沸点数据来自 `api.juejin.cn` 公开接口，不需要登录。
- **点赞和评论走掘金 `interact_api`，需要登录**：请求是在你已打开的掘金页面上下文里发出的，
  用的是你自己的 cookie。实测未登录时接口返回 `must login`；评论接口的字段名可能随版本变化，
  如果发失败，扩展会自动把内容复制到剪贴板让你去原文粘贴。
- 点评内容严格只针对现象，不针对发帖人；遇到疾病、失业、裁员赔偿等话题会收起机锋写人话；
  不碰政治、领土、民族、宗教相关评论。
