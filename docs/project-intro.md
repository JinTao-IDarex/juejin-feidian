# 我把掘金沸点做成了一副扑克牌，还让 AI 逐张毒舌点评

> 沸点抽卡（juejin-boom）：一个开源的「掘金沸点翻牌站 + 浏览器扩展」。60 张沸点一副牌，← → 翻着看，每张配一句 AI 点评，顺手复制就能贴进评论区。

## 一、这是个什么东西

每天刷掘金沸点，一屏一屏地滚，信息密度低，乐趣也有限。于是我把它改造成了另一种形态——**一副牌**：

- **翻牌**：60 条沸点洗成一副牌，主卡居中，左右是虚化的邻卡。`←` `→` 逐张翻，空格抽下一张，按 `S` 洗牌（实时拉最新沸点）。
- **AI 点评**：右侧的 AI 卡给当前这张牌配一句点评。五种预设风格一键切换——**毒舌 / 温柔 / 理性 / 吃瓜 / 文青**，同一张牌能读出五种完全不同的味道。
- **批量点评**：不想一张张点？一键让 AI 把整副牌逐张写完，边生成边上卡。
- **浏览评论**：右侧卡组往上滑，还能翻这条沸点下的真实评论。
- **音效与动效**：Web Audio 实时合成的纸牌咔哒声（默认静音，`M` 开关）；动效三档（完整 / 轻量 / 跟随系统），低配机器也流畅。

它有两个形态：

1. **本地站点**——`npm run dev` 起一个零依赖的 dev server，浏览器打开就能玩；
2. **浏览器扩展**（Chrome MV3）——装上之后，掘金页面右上角浮一张缩略卡，点开就是同款牌桌，背景虚化，看完点遮罩收起，不干扰正常刷沸点。

## 二、隐私是底线：不上传、不代发、Key 自持

这个项目**没有后端、没有账号体系、不上传任何数据**。AI 接口用的是你自己的 Key：

- 站点版可以把 Key 写在服务端的 `site/.ai-config.json` 或 `JB_AI_*` 环境变量里，Key 完全不进浏览器；
- 扩展版 Key 存在扩展页自己的 localStorage，只在你本机。

「一键代发评论」功能曾短暂上线，目前已**主动下线**（掘金网关对代发请求有 CSRF 拦截，稳妥起见先收回来）。现在所有 AI 卡上的按钮一律是「复制点评」——点一下复制，贴进评论区、按下发送的永远是你自己的手。代发链路在代码里原样保留，开关只有一个布尔值。

厂商声明表里也**永远不放密钥**——表里只写「这家厂商要不要 Key、去哪申请」。

## 三、AI 接入：厂商表与协议解耦

点评能力支持 **OpenAI / Anthropic Claude / DeepSeek / Kimi / 智谱 GLM / Z.ai / 阿里百炼 / 硅基流动 / 火山方舟 / 腾讯混元 / OpenRouter / Gemini / 本地 Ollama**，以及任意 OpenAI 兼容的自建网关（one-api / new-api / LiteLLM 选「自定义」即可）。

设计照着 ZCode 的 provider 配置来的，核心是一条解耦原则：**厂商只提供 baseUrl 和模型名，请求的形状由「协议」决定**。全项目只支持三种协议：

| 协议 | 端点 | 用在哪儿 |
|---|---|---|
| `chat` | `POST /chat/completions` | 绝大多数厂商的 OpenAI 兼容接口 |
| `responses` | `POST /responses` | OpenAI 新接口（Codex 系列只能跑在它上面） |
| `anthropic` | `POST /messages` | Claude 原生协议 |

这套声明表（`providers.js`）是一份 UMD 文件，浏览器、Node、扩展三端加载同一份。新增一家厂商 = 表里加一条数据，**不用动任何调用代码**。模型级的怪癖（o 系列和 gpt-5 不吃 `temperature`、推理模型的思考 token 要占输出上限……）也全部写在声明表的正则规则里，弹窗会把最终的协议判定结果当场显示出来，不用等上游报错再猜。

批量点评的节奏也调过：整副牌按每 5 条一组排队、任意时刻最多 1 个在途上游请求（不打爆限流），同一批共用一个 session、接在同一场多轮对话里（模型接着自己上一轮的格式继续写），一组回来先上一批卡，失败按 3s / 8s 退避重试。站点服务端再叠一层 AIMD 自适应并发——成功就逐步放宽、遇到限流立刻减半、超时把批次拆半。

## 四、一份前端，三端跑

这是我在这个项目里最满意的一个工程决策：**站点前端只有一份源头，扩展是它的宿主，不是第二个实现。**

`extension/` 里的 `app.css` / `app.js` / `data.js` / `host.html` 全部由 `scripts/build_extension.py` 从 `site/` 生成——逐字节拷贝，外加唯一一处三行补丁（放行 `chrome-extension:` 协议下的两个接口闸门，构建脚本会校验补丁必须命中 2 次，失配直接报错退出）。扩展里没有服务器，`api.mjs` 把 dev server 的 5 个接口逐字移植过去；页面拿到接口的方式更简单——`api-shim.js` 只劫持 `/api/*` 的 `fetch` 转发给 background，**站点 JS 一行都不用改**。

结果是：牌面、动效、AI 配置弹窗、点评风格……站点上是什么样，扩展里就是什么样，而且**永远不可能各自漂移**。同一份前端还能直接当本地预览页跑，构建脚本自带静态自检（清单引用、JS 语法、注入顺序、补丁次数）。

## 五、跑起来

```bash
git clone <本仓库>
cd juejin-boom
npm install && npm run dev   # http://127.0.0.1:7100
```

浏览器扩展：到 Releases 下载 `juejin-feidian-card-extension.zip` 解压，Chrome 打开 `chrome://extensions/` 开启开发者模式，「加载已解压的扩展程序」选中解压目录，打开掘金即可。详细的扩展使用说明见 [`extension-user-guide.md`](extension-user-guide.md)。

不配 Key 也能玩——内置一副 60 张的离线牌堆，实时拉取失败自动兜底；配上 Key 才解锁 AI 点评。
