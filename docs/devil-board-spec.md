设计稿：`掘金沸点 · 魔鬼榜单`（Ardot，fileId `729148858522953`）
导出图：`output/devil-board-deal/*.png`

一句话：每天/每周抓一次掘金沸点，筛出候选，让 AI 按 6 条互斥的赛道打分，每条只进分最高的那个榜；
首页是**六摞牌**，点一摞进**该赛道的详情页**（顶牌飞入牌台中央，默认第 1 张），
再用**箭头 / 键盘 ← → / 左右滑动**逐张往下翻。榜单条数由当天候选决定，不固定。

## 一、六个赛道

| 赛道 | 评分锚点（三个维度，各 1–10） | 赛道色 |
|---|---|---|
| 毒舌榜 | 攻击性 · 精准度 · 共鸣 | `#FF5A3C` |
| 离谱榜 | 荒谬度 · 自信度反差 · 反驳空间 | `#FF7A1A` |
| 阴阳榜 | 隐晦度 · 反讽强度 · 表面礼貌反差 | `#A855F7` |
| 嘴硬榜 | 死不认错程度 · 事实偏差 · 理直气壮度 | `#1E80FF` |
| 废话榜 | 信息密度（越低分越高）· 术语密度 · 字数/信息量反差 | `#8A9099` |
| emo 榜 | 情绪浓度 · 共鸣广度 · 自嘲刀法 | `#4A5B8C` |

**互斥规则**：候选池是共享的一份（48 条），AI 对每条同时打 6 个赛道的分，最后每条沸点**只进它得分最高的那一个榜**。
避免同一条内容霸占 6 个榜单——那会让榜单变成"重复播放"。

## 二、抓取：实测结论（这是整个功能的前提）

`scripts/_probe_range.py` 实测（2026-09-24 08:30）：

| sort_type | 翻 60 页 | 条数 | 覆盖跨度 | 耗时 |
|---|---|---|---|---|
| 300（时间序，项目现用） | 1193 条 | **1.76 天** | 43.8s |
| 200（热度序） | 1188 条 | **14.33 天** | 44.7s |

三条硬约束：

1. **日榜用 300，周榜必须用 200**。300 翻 60 页才够到 1.76 天，永远摸不到 7 天。周榜用 200（热度序），约 30 页覆盖一周。
2. **ctime 不是严格降序** —— 不能"翻到昨天 0 点就早停"，必须**整段翻完再按 ctime 过滤**。
3. **一次全量 20–45 秒、上千条** —— 榜单绝不能实时算，必须落盘 + 后台预热。

建议参数：

```
日榜：sort_type=300，翻至 ctime < 今日 00:00 或 40 页上限
周榜：sort_type=200，翻至 ctime < 7 天前或 45 页上限
```

## 三、评分流程（两段式，别让 AI 裸打分）

**第一段 · 入围（确定性，不烧 token）**
从抓到的上千条里筛出 48 条候选：
- 硬过滤：正文 ≥ 12 字；无正文的纯图/纯链接直接出局
- 热度分 = `log(1+digg)*0.6 + log(1+cmt)*0.4`，取 Top 48

**第二段 · 定名次（AI）**
- 对 48 条候选批量请求：每条返回 6 个赛道分 + 一个"赛道分"（1–10，一位小数）+ 一句判词 + 三个维度分明细
- 分块 8 条/次，约 6 次请求，20–40s
- **复用现有 `/api/roast` 那条链路**：并发队列、内存缓存、拆半重试都已现成，不要另起一套

**关键口径：热度只决定入围，不决定名次。** 掺了热度就退化成热帖榜，AI 的判断才是这个功能的灵魂。

**可复现**：结果落盘 `data/board/day-YYYY-MM-DD.json` / `week-YYYY-Www.json`，同一天重开直接读盘，不重复烧 token。
缓存 TTL：日榜 6 小时，周榜到自然周结束。

## 五、榜单宪章（硬边界，不是可选项）

AI 给真人公开发言排"最恶毒"的名次，天然会越界。四条规矩：

1. **评内容，不评人**。禁止基于作者身份、公司、职位、地域、外貌评分。
2. **不进榜**：涉政、涉黄、人身攻击、真实姓名指向的条目，直接剔除（AI 拒答即跳过，不追问、不三次重试）。
3. **可自辩**：每条带原文链接，被评的人能点进去看到出处。
4. **宁可空着**：候选不足时显示空态，不硬凑第一名。

## 六、版式：六摞牌 → 详情页 → 切牌

三层：**首页（六摞牌）** → **赛道详情页** → **逐张切牌**。

### 6.1 首页 · 六摞牌

- 一摞 = 三张同宽竖版牌**垂直堆叠**，底下两张各向下错开 9px，只露出下边缘的白边（这就是"一摞"的全部视觉）
- 最上面那张是**封面牌**，语序自上而下：角标行（名次 + 赛道符号 · 最高分）→ 形象插画 → **赛道名（巨字）** → 定义 →「点击进入 · 看完整榜单」
- 底下两张是**空白牌背**（白底 + 描边），没有内容 —— 内容等进了详情页才翻

**封面牌是"封面"不是"信息卡"（2026-09-24 改版口径）。** 旧版赛道名只有 15px，和 10px 的定义挤在一个量级，
六摞并排看像六张参数卡，没有主次。改版把**赛道名一次拉到 34px**，并且：

| | 旧版 | 现版 | 为什么 |
|---|---|---|---|
| 赛道名 | 15px Bold 墨黑 左对齐 | **34px Black 赛道色 居中** | 一次放大到 2.3 倍，成为唯一的视觉主角；用赛道色是为了六摞并排时**一眼分得开** |
| 名次 | 17px Inter Bold | **20px Inter Black 赛道色** | 跟随放大，但**不能跟着标题一起翻倍** —— 它是配角的锚点 |
| 分数 | 15px Inter Bold | **20px Inter Black 赛道色** | 与名次同档，两端对称 |
| 赛道定义 | 10px `#8A9099` 左对齐 | 11px `#6B7280` 居中 | 标题放大后原来的浅灰会被彻底压没，必须加深一档 |
| 牌内间距 | 7 | **5** | 见下 |
| 角标行高 | 26 | **28** | 容纳 20px 的字 |

⚠️ **放大标题会挤掉形象区，而形象区有硬下限。** 34px 标题比 15px 多吃 22px 高度，
这些只能从形象区扣。同时**形象区是 `scaleMode:FILL`——高度一变就按宽度放大后裁上下**，
裁过头会把角色头顶的配件切掉（**emo 的雨云、废话榜的三个气泡**最贴顶，是最先牺牲的两个）。

核算：固定项 = padding 24 + 角标行 28 + 标题 44 + 定义 16 + 提示 14 + 间距 4×5 = 146，
**形象区 = 283 − 146 = 137**。137 / 178 对应上下各裁 11.5%，实测雨云和气泡**刚好完整**——
**这就是下限，不要再往下压**。所以才把牌内间距从 7 收到 5、角标行压在 28（而不是 32）。
以后再想加元素，必须先从别处腾高度，不许直接吃形象区。

### 6.2 详情页 · 发牌入场

- 点任一摞 → 路由到该赛道详情页（`/board/:id`）；六摞整体淡出，**顶牌飞到牌台中央**并放大到详情尺寸
- 详情页结构：Header → 面包屑（`返回 · 六摞牌  /  毒舌榜 · 共 12 张`，**条数动态**）→ **牌台** → 切牌进度 → Footer 规则说明
- 牌台 = 左箭头 + 大牌 + 右箭头，大牌**纵向居中**
- **默认展示第 1 张（Top1）**，此时左箭头置灰 —— 已经在第一张，没得往回翻

### 6.3 切牌

- 点 **→** 换下一张：旧牌左出、新牌右入，两段同时跑 —— 交接的时候牌台一直是满的，中间不留空档
- 第 2 张起左箭头点亮，两个方向都能翻；翻到末张时右箭头置灰
- 反向点 **←** 是同一套动画的镜像
- **三种换法完全等价**：点箭头 / 按键盘 ← → / 左右滑动（细则见 6.5）

### 6.4 ⚠️ 条数不固定，所有数字必须动态

榜单条数由当天候选决定，**1 ~ N 张都可能**，绝不能写死 3。三处涉及数字的地方：

| 位置 | 设计稿写法 | 口径 |
|---|---|---|
| 封面牌（首页） | `点击进入 · 看完整榜单` | **刻意不写数字** —— 还没进详情页，条数没有意义，也避免和详情页打架 |
| 详情页面包屑 | `毒舌榜 · 共 12 张` | 数字动态 |
| 进度文字 | `第 3 张 / 共 12 张` | 两个数字都动态；只剩 1 张时左右箭头**同时置灰** |

**缩略进度不能用固定几格**，改成**横向滚动轨道**：轨道内放 N 个缩略卡，当前项白底 + 赛道色描边 + 略微放大；
超出可视区时轨道横滚，当前项自动滚到可视区中间。
设计稿里画了 **12 张**作示例 —— 只为说明"数量可以很多"，**不是上限**。条数少时轨道自然留白，不做拉伸填充。

### 6.5 三种换法细则

| 方式 | 行为 |
|---|---|
| **点箭头** | 点哪儿走哪儿；到头的那一侧箭头置灰、不可点 |
| **键盘 ← →** | 详情页有焦点时生效；连按走多张，**不做加速**；输入框 / 文本框内不拦截；`Esc` 返回六摞牌 |
| **左右滑动** | **向左滑 = 下一张，向右滑 = 上一张**（跟手方向与牌的运动方向一致） |

滑动的三条实现细节：

1. **跟手**：拖动过程中牌直接跟随位移，**松手之前不播动画**（不要既跟手又自动走）
2. **吸附阈值**：拖动距离超过牌宽 **25%** → 判定换张，播 320ms 动画补完；未超过 → 弹回原位（160ms）
3. **拖动时箭头让位**：两个箭头淡出，避免和手指 / 光标打架；松手后按新状态恢复

### 6.6 尺寸规格

**⭐ 第一条硬规矩：所有卡牌严格按标准扑克牌比例 1 : 1.4。**
不分封面牌 / 牌背 / 详情大牌 / 缩略卡 / 动画分帧里的牌，**全部同一口径**。
牌是这页的视觉主体，比例一歪整摞牌立刻变成便签纸 —— 这是**不许按内容自适应高度**的地方。

| | 站点页（1440×1000） | 扩展浮层（1440×722） |
|---|---|---|
| Header | 96 | 56 |
| 摞（含底部错开 9×2） | 202 × **301** | 202 × **301** |
| 六摞间距 | 36（6×202 + 5×36 = 1392，正好撑满） | 30 |
| 面包屑 | 40 高 / 12px 字 | 32 高 / 11px 字 |
| 大牌 | 396 × **554** | 300 × **420** |
| 大牌形象区 | 356 × 249（`fill_container`） | 268 × 176（`fill_container`） |
| 左右箭头 | 40 × 40 圆 | 32 × 32 圆 |
| 箭头 ↔ 大牌间距 | 28 | 22 |
| 缩略卡（当前 / 其他） | 24×**34** / 20×**28** | 20×**28** / 16×**22** |
| 缩略轨道 | 320 × **40**，gap 6，超出横滚 | 260 × **34**，gap 5，超出横滚 |
| 切牌进度整行 | 高 56，内容居中 | 高 48，内容居中 |
| 键帽（← →） | 16 × 16 | 14 × 14 |
| 牌台 ↔ 面包屑 / 进度条 | 16 | 16 |

比例自检：202/283、396/554、300/420、24/34、20/28、16/22 —— 全部 = 1 : 1.4（取整到像素）。

**牌高写死之后，长内容靠「形象区」吸收。** 封面牌与详情大牌的**形象区高度改成 `fill_container`**
（原来的「弹性占位」frame 已删除，两段空间合并成一个形象区）：
角标行 / 标题 / 正文 / 按钮全是内容自适应，形象区吃掉剩下的全部高度。
所以**文案加长 → 牌高不变、形象区变矮**，牌框永不被撑开。真正的常量只有三个宽度：202 / 396 / 300。

**连带项（改牌高时必须一起动）**：形象区（改 `fill_container`）、
切牌屏四帧里箭头与牌的纵坐标（牌变矮后箭头要跟着重新居中）、
牌堆区的 `counterAxisAlignItems: "CENTER"`（否则摞贴顶、下方空一截）。

两屏的牌尺寸一致；浮层不是缩水版，只换 Header、面包屑、箭头和字号档位。

## 七、两段动画

### A. 入场：点一摞 → 牌飞入牌台（320ms）

四帧是同一段动画的四个采样点：

| 时间 | 事件 | 细节 |
|---|---|---|
| **0ms** | 按下 | 整摞 `scale 0.97` + 下沉 4px，先给一个"被按到"的反馈，然后才开始飞 |
| **80ms** | 弹起 | 顶牌从摞里被抽出来（上抬 + 右移）；另外两张留在原地开始淡出 |
| **180ms** | 展开 | 牌飞向牌台中央，同时放大到详情尺寸 |
| **320ms** | 落位 | 居中落位（396 × 554，标准扑克比例）；其余五摞同时淡出、牌堆退场。从这一刻起可以点 **→** 切牌 |

### B. 切牌：箭头 / 键盘 / 滑动（共用一套）

四帧是同一段交互的四个采样点：

| 帧 | 事件 | 细节 |
|---|---|---|
| **1 · 静止** | 待命 | 当前牌在位；第 1 张时左箭头置灰、右箭头可用 |
| **2 · 拖动中** | 跟手 | 牌随拖动位移，**箭头淡出让位**；下一个方向从对侧露出牌边 |
| **3 · 松手 · 160ms** | 交接 | 旧牌左出、新牌右入，两段重叠着跑 —— 牌台始终不空 |
| **4 · 到位** | 落位 | 新牌归位，左箭头点亮；缩略轨道走到当前格 |

- **点箭头 / 按 ← → 跳过第 2 帧**，直接走 1 → 3 → 4
- 只有滑动会走满四帧；未超过吸附阈值时从第 2 帧弹回第 1 帧

- 缓动统一用 `cubic-bezier(0.22, 1, 0.36, 1)`（先快后慢，带轻微过冲再回弹）
- **返回上一层 = 入场动画倒放**，时长压到 240ms（收比起手要快）
- **实现口径**：牌用 `position:absolute`，靠 `transform: translate3d()` + `scale()` 驱动，
  **不要改 width/height** —— 十个元素同时改宽高会触发 layout 重排，掉帧。用 CSS 变量（`--x/--y/--s`）写关键帧。
- 切牌的出/入两段共用一条时间轴，一进一出；`prefers-reduced-motion` 下直接跳变，不播动画。

**系统状态（沿用）**
- 评分中：进度条 + `已扫描 x 条 · 筛出 48 条候选 · 打分 12/48`
- 空态：今日暂无上榜
- 失败：接口超时，保留上次结果并标「旧」，不覆盖已发布榜单

把 34px 搬到详情页会喧宾夺主，把 15px 搬回封面会退回"参数卡"。

**作者行**：左 `@作者` 12px `#5C636E`，右 `赞 128 · 评 36` 12px `#8A9099`（浮层各降一档到 11px）。

封面牌与详情大牌**共用「角标行 + 形象区」这套结构**（尺寸和字号各自一套，见上表）—— 实现时做成同一张牌的 `cover` / `detail` 两个状态最省事，
**别复制成两个组件**（改一处要改两遍）。

## 九、六张卡牌形象

每赛道一个角色，**同一个物种（土星虫）的性格变体** —— 换性格、换道具、换配色，不换血统。

| 赛道 | 文件 | 关键识别特征 |
|---|---|---|
| 毒舌榜 | `assets/board-cards/c1-vicious.png` | 分叉舌喷出小火苗 + 头顶两只恶魔角 + 半眯眼坏笑 |
| 离谱榜 | `assets/board-cards/c2-absurd.png` | 螺旋眼 + 头歪到不可能的角度 + 环绕问号 + 悬空离地 |
| 阴阳榜 | `assets/board-cards/c3-passive.png` | 半脸甜笑闭眼 / 半脸冷眼，一手背后藏刀 |
| 嘴硬榜 | `assets/board-cards/c4-stubborn.png` | 钢牙紧咬 + 四臂抱胸 + 旁边一面裂了的盾 |
| 废话榜 | `assets/board-cards/c5-blah.png` | 3 个**完全空白**的对话气泡 + 死鱼眼 |
| emo 榜 | `assets/board-cards/c6-emo.png` | 头顶自带雨云 + 抱膝 + 一滴泪，金环也跟着塌了 |

并排看板：`devil-board-cards.miora`（6 张横排对比）。

**血统基线**（与 `assets/mascot-saturn.png` 对齐，别丢）：橙身体 `#FF7A1A`、金色土星环、四条小短腿、
**金褐色镜片眼 + 深色描边与中隔**、墨黑描边、扁平卡通 + 轻赛璐珞。

**生成口径**：`ImageGen` 图生图，`image1 = assets/mascot-saturn.png`，`input_fidelity: high`、
`quality: high`、`size 1024x1024`；纯白底、**无文字、无牌框**（牌框和文字由设计稿自己画 ——
图里再带一份会和版式打架）。

⚠️ **并行发多张会互相覆盖**：ImageGen 在并行调用时 `output_dir` 会串到同一个目录，且返回同名文件
（实测 3 张并行只剩 2 张）。**一张一张发**，或每张给独立子目录。

## 十、配色与组件

- 沿用项目现有语言：掘金蓝 `#1E80FF`、墨黑 `#1A1D21`、白卡 + `#F4F5F7` 底、圆角 12–20
- 6 个赛道色同时用于：图标底（14% 透明）、最高分徽章底（10%）、赛道符号、名次 1 的数字、分数、判词、形象区底色（7%）
- 字体：`Noto Sans SC`（中文）/ `Inter`（数字）；数字用 Bold
- 图标全部为 SVG frame（火焰 / 问号 / 阴阳半圆 / 盾牌 / 气泡省略号 / 雨云），无 emoji
