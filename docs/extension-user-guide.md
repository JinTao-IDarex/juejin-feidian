# 沸点抽卡 · 浏览器扩展使用说明

在 juejin.cn 页面上悬浮一个「沸点抽卡」牌桌：翻牌看当日沸点，配一句 AI 点评，一键复制贴进评论区。本文面向使用者；设计与架构见 [`extension/README.md`](../extension/README.md)。

当前版本：v0.2.15（Chrome / Edge 等 Chromium 内核浏览器，MV3）

---

## 一、安装

> 扩展未上架商店，需以「开发者模式」加载。加载后 Chrome 每次启动可能提示「请停用开发者模式运行的扩展程序」，点「取消」即可正常使用。

### 方式 A：下载发布包（推荐）

1. 到本仓库的 **Releases** 页面，下载 `juejin-feidian-card-extension.zip`；
2. 解压到任意**固定目录**（确认 `manifest.json` 在解压目录的根部；之后不要移动或删除该目录，扩展是直接引用它的）；
3. 浏览器打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），打开右上角（Edge 为左侧）的**开发者模式**；
4. 点「**加载已解压的扩展程序**」，选中第 2 步的解压目录；
5. 打开或刷新任意 `juejin.cn` 页面，右上角出现一张缩略卡，即安装成功。

### 方式 B：从源码构建

```bash
git clone <本仓库>
cd juejin-boom
python scripts/build_extension.py   # 从 site/ 生成 extension/（自带补丁校验与静态自检）
```

然后按方式 A 的第 3–4 步，选中仓库里的 `extension/` 目录。

## 二、上手 30 秒

扩展只有两个状态：

- **收起**：掘金页面右上角一张缩略纸牌（不压掘金头部图标）；
- **展开**：牌桌端到页面正中，底下铺一层全屏虚化遮罩。

| 动作 | 操作 |
|---|---|
| 展开 | 点右上角缩略卡 |
| 收起 | 点浮层右上角的收起钮 / 点遮罩任意空处 / 按 `Esc` |
| 工具栏图标 | 等价于收起 ⇄ 展开开关 |

展开后：主卡在页面正中，`←` `→` 翻牌，右侧是 AI 点评卡。**不配置 AI 也能翻牌**（内置 60 张离线牌堆兜底），只是没有点评。

---

## 三、快捷键

| 键 | 作用 |
|---|---|
| `←` / `→` | 翻上一张 / 下一张 |
| `空格` | 抽下一张 |
| `↑` / `↓` | 翻右侧卡组（AI 点评 / 真实评论） |
| `S` | 洗牌——拉最新沸点重洗一副 |
| `L` | 点赞当前这条沸点 |
| `C` | 新标签页打开当前这条沸点 |
| `M` | 纸牌音效开关（默认静音） |
| `Esc` | 关闭弹窗；无弹窗时收起为缩略卡 |

收起状态下 `←` `→` `空格` 仍然可用（盲翻，迷你卡会跟着动）；`S`、`M` 任何时候都可用。输入框聚焦时快捷键自动屏蔽，不会干扰你打字。

## 四、配置 AI 点评（三步）

1. 展开浮层，点右上角的 **✦**；
2. **选厂商 → 填 Key → 完成**（常用厂商的默认模型已预填，接口协议自动判定并当场显示）；
3. 回到牌桌，右侧 AI 卡点「生成」，或直接用「风格」钮换毒舌 / 温柔 / 理性 / 吃瓜 / 文青。

**隐私**：Key 只存在扩展页自己的 localStorage，仅本机使用；本项目不上传任何数据，厂商声明表里也永远不含密钥。

### 厂商速查

| 厂商 | 协议 | 备注 |
|---|---|---|
| OpenAI / DeepSeek / Kimi / 火山方舟 / 腾讯混元 / 硅基流动 / 阿里百炼 / OpenRouter | OpenAI 兼容 | 填 Key 即用 |
| Anthropic Claude | Anthropic 原生 | `sk-ant-` 开头的 Key |
| 智谱 GLM / Z.ai（**Coding Plan**） | Anthropic 兼容 | ⚠️ 见下方提示 |
| 智谱 BigModel / Z.ai（标准 API） | OpenAI 兼容 | 与 Coding Plan 是**两套计费** |
| Google Gemini | OpenAI 兼容层 | 走官方兼容端点 |
| 本地 Ollama | OpenAI 兼容 | 无需 Key |
| 自定义 | 自选 | 自建网关（one-api / new-api / LiteLLM）填地址与模型名 |

> ⚠️ **Coding Plan 提示**：智谱 / Z.ai 的 Coding Plan 钥匙只开通了 **Anthropic 兼容端点**，务必选「GLM Coding Plan」/「Z.ai Coding Plan」这一项；选成标准 API 会报「余额不足」（那是另一套按量计费）。GLM-5.x 走该端点时扩展会自动关闭思考模式，避免输出预算被思考 token 吃光。

### 批量点评

「批量」会一次给整副牌逐张生成点评：每 5 条一组排队、组内接着同一场对话写（风格连贯），一组回来先上一批卡；中途失败的组会自动重试两次。上游限流或 Key 额度耗尽时会停下并报错，稍后再点继续即可。

## 五、常见问题

**Q：右上角没有出现缩略卡？**
刷新页面；确认扩展在 `chrome://extensions/` 里处于启用状态；确认当前页面在 `juejin.cn` 域下。

**Q：为什么按钮是「复制点评」而不是直接发评论？**
「一键代发」已主动下线（掘金网关对代发请求有 CSRF 拦截）。现在点击只复制到剪贴板，粘贴、发送都由你亲手完成。代发链路在代码里保留，随时可恢复。

**Q：生成点评报「余额不足」？**
多半是智谱 / Z.ai 的 Coding Plan Key 选错了厂商条目，见上节「Coding Plan 提示」。

**Q：AI 返回了空内容？**
推理模型的思考 token 会吃掉输出上限，扩展已对已知模型自动处理；若是自定义厂商，检查模型名拼写与 Key 是否有效。

**Q：批量点评跑到一半停了？**
上游限流或额度不足。扩展已按 3s / 8s 退避重试，仍失败才停；等一会儿再点继续，已生成并缓存的点评不会丢。

**Q：没有声音？**
默认静音，按 `M` 打开纸牌咔哒声。

**Q：我的数据 / Key 会被上传吗？**
不会。项目无后端、无账号体系、无任何统计埋点；Key 存在本机浏览器里，请求由你的浏览器直接发给你所选的 AI 厂商。

**Q：会影响正常刷掘金吗？**
收起后只在右上角留一张 148×196 的缩略卡，遮罩与虚化层在收起时完全移除，不占合成层。

## 六、卸载

`chrome://extensions/` → 找到「沸点抽卡 · 掘金沸点翻牌」→「移除」即可。Key 与本地缓存在浏览器里随扩展一并清除；若以后重装，需重新填 Key。

遇到问题或想加厂商，欢迎到仓库提 issue。
